# Quickstart

New to Raycast? Start with this guide to get started with the basics of the app on Mac and Windows.

Raycast is the fastest interface to get work done on your computer: a launcher where you can find apps, files, folders, windows, links, commands, AI, snippets, and more from one place.

This guide walks you through a few basics to get started. Raycast can do a lot, so start with the fundamentals. Part of the fun is discovering more of Raycast as you use it.

Let's go.

### Search Your System

Files, folders, and apps are searchable directly from Root Search. Press your Raycast hotkey, start typing, and select something you use often without opening Finder or File Explorer.

  Read the [File Search page](https://manual.raycast.com/file-search) for more information.

### Use the Action Panel

The Action Panel unlocks much of what Raycast can do. With an app, file, folder, command, or search result selected, press `⌘ K`/`Ctrl K`. From here, you can discover every action available for the selected item.

  Read the [Action Panel page](https://manual.raycast.com/action-panel) for more information.

### Create a Quicklink

Quicklinks turn the places you open all the time into searchable shortcuts. Open **Create Quicklink**, add a URL, file, folder, or app path, give it a name, then open it later from Root Search like anything else in Raycast. You can also find it any time with the **Search Quicklinks** command.

  Read the [Quicklinks page](https://manual.raycast.com/quicklinks) for more information.

### Set a Hotkey

Now try one of those actions. Select an app you use regularly, or search for the Quicklink you just created. Open the Action Panel with `⌘ K`/`Ctrl K`, choose **Configure Command → Set Hotkey**, then press the shortcut you want to use. You can now open that app or Quicklink from anywhere using that shortcut.

  **Tip:** Combine `⌥`/`Alt` with the first letter of the app as an easy system to get started.

  Read the [Command Aliases & Hotkeys page](https://manual.raycast.com/command-aliases-and-hotkeys) for more information.

### Chat with Raycast AI

Raycast AI has two ways you can chat with AI. Press `Tab` from Root Search for **Quick AI**, ideal for fast one-off questions. For longer conversations, open **AI Chat** to ask follow-ups, share attachments, switch models mid-conversation, and pick up where you left off at any time.

  Read the [Quick AI](https://manual.raycast.com/ai/quick-ai), [AI Chat](https://manual.raycast.com/ai/ai-chat), and [AI Extensions](https://manual.raycast.com/ai/ai-extensions) pages for more information.

### Install an Extension

The Store is home to thousands of community-built extensions. Browse [**Store**](raycast://extensions/raycast/raycast/store) in Raycast or [on the web](https://raycast.com/store), then install one that looks useful.

  **Tip:** If you're not sure where to start, try something fun like **GIPHY**. Once installed, search for a GIF and paste it into a chat.

  Read the [Extensions page](https://manual.raycast.com/extensions) for more information.

### Try some Everyday Essentials

Over the next few days, try a few of Raycast's built-in essentials as they come up in your day to day:

  - [Clipboard History](https://manual.raycast.com/clipboard-history): Open **Clipboard History** to find something you copied earlier and paste it again.
  - [Calculator](https://manual.raycast.com/calculator): Type a calculation, conversion, date, or currency question directly into Root Search.
  - [Emoji & Symbols](https://manual.raycast.com/emoji-symbols): Open **Search Emoji & Symbols**, find an emoji or symbol by name, and paste it into the app you're using.
  - [Snippets](https://manual.raycast.com/snippets): Save text you type often, then paste it anywhere with a short keyword.
  - [Window Management](https://manual.raycast.com/window-management): Move and resize windows with commands like **Left Half**, **Maximize**, or **Next Display**.

Practice these basics for a few days and you'll start to feel Raycast becoming part of how you move around your computer.

When you're ready, the [Raycast Manual](https://manual.raycast.com) has more features for you to try. You can also use `@manual` in AI Chat or Quick AI to ask for help.
